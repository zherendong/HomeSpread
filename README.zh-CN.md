# HomeSpread 中文 macOS 版

在 Mac 上展开 iPhone 的多页主屏幕。iPhone Duo 与小组件布局可离线预览，并在独立草稿中交换同页普通 App；手机写入仍禁用。未知结构保持只读。通过能力检查的普通设备布局保留原有编辑流程。

本分支基于 [humanlyj/HomeSpread](https://github.com/humanlyj/HomeSpread) 的提交 `0cfbc6866e9748105cbc3c9e743ad0b1788e6775`。这是中文 macOS 移植版，版本 `1.0.22-mac.zh.3`，保留 GPL-3.0-or-later 许可和原作者历史。来源核查见 [PROVENANCE.zh-CN.md](PROVENANCE.zh-CN.md)，原仓库的 Windows 说明见 [README.md](README.md)。

## Duo 与小组件：只读预览

1. 打开应用，点击“打开备份文件”，选择本机已有的 `.plist` 布局备份，无需连接手机。
2. 在“预览布局”中选择“iPhone Duo · 双页预览”。每两个逻辑页并排，程序坞在右侧；没有下一页时显示提示，不创建或写入空白页。
3. 小组件按实际占位显示：小号 2×2、中号 4×2、大号 4×4。堆叠显示成员数量。卡片只是布局占位示意，不获取或伪造天气、健身等实时内容。
4. 标题分别显示项目数和占用格数。尺寸或位置不能确定的条目单独列出，不挤入一格、不静默丢弃。可展开文件夹、缩放和切换预览，但不能拖放、重命名、增删页面。

**Duo、含小组件、未知项或空位的布局，禁止应用修改、恢复和原样写回校验。** 这条能力限制优先于会话校验标记和备份恢复入口；旧的校验成功、切回逐页模式、使用没有小组件的旧备份均不能绕过。此版本不提供 Duo 真实写回测试。

离线预览只读取指定备份及已有图标缓存，不自动连接手机、查询安装清单或下载图标。原始备份不修改；小组件的原始字段、堆叠成员和逻辑分页保留。预览中的跨格排布依据返回顺序和组件尺寸建模，不承诺完整重现系统未返回的隐藏页面、任意空隙和折叠姿态。

```sh
./run_macos.command --preview /path/to/layout.plist --profile duo
```

## 离线草稿编辑

1. 点击“打开备份文件”，选择已有 `.plist`；按需选择“iPhone Duo · 双页预览”。整个流程无需连接手机。
2. 点击“开始离线草稿”。在同一个逻辑页面依次选择两个普通 App，再点击“交换所选 App”。两个页面即使并排显示，也不能跨页交换。
3. 侧栏列出原始布局到草稿的最终差异。使用“原始布局”和“草稿布局”按钮对照；原始视图不能执行交换。
4. 使用“撤销”“重做”调整草稿。只能交换页面中的普通 App，不开放文件夹内容、Dock、小组件、拖放、分组、重命名或增删页面。
5. 点击“保存草稿”，另存为 `.hsdraft` 文件。以后通过“打开草稿”继续；打开时会重放保存的交换步骤并核对最终布局。保存只保留当前有效步骤，已撤销的重做分支不写入文件。
6. “结束草稿”回到原始布局的离线预览。关闭、切换文件或结束草稿前，未保存内容提供保存、放弃和取消选择。

**草稿不是手机备份，也不是写入许可。** 原始 `.plist` 文件不变；`.hsdraft` 使用独立格式，不能在“从备份恢复”中使用。草稿中包括原始布局、候选布局、交换步骤与完整性摘要，包含个人应用信息，应保存在本机并避免公开分享。默认保存位置为资料目录的 `drafts/`，也可以在保存窗口选择其它目录。

草稿期间禁止读取设备、下载图标、应用修改、恢复和原样写回校验。草稿操作不进入设备工作线程，切换预览方式或伪造会话校验标记不能解除写入限制。布局不符合已验证的结构、尺寸或容量约束时，不开启草稿。

```sh
./run_macos.command --draft /path/to/layout.hsdraft --profile duo
```

## 支持编辑的普通布局

1. 在 Finder（访达）中双击 `dist/HomeSpread.app`。程序包含 Python 和 Qt，不需要另装 Python、iTunes 或 Apple Devices。
2. 用数据线连接一台 iPhone，解锁，在手机上确认“信任此电脑”。保持连接与解锁。
3. 点击“从设备读取”。点击“获取图标”即可显示应用图标。
4. 仅在设备及布局通过能力检查时，若要写回，在开始编辑前点击“原样写回校验”。它会在明确确认后备份、真实写回当前布局并核对读回结果；也可能触发下述 App 资源库回填。未通过校验时禁止应用编辑。对于通过能力检查的设备及布局，为便于故障恢复，仍可在单独确认风险后恢复同设备的校验备份；恢复后读回核对通过也会建立当前会话的编辑写入许可。每次重新读取或操作失败后需重新校验。
5. 拖动应用调整位置；双击文件夹查看内容。按住 **⌘ Command** 点选多个应用，按 **⌘G** 新建文件夹；**⌘Z** 撤销，**⇧⌘Z** 重做。文件夹名称也可用工具栏“重命名”修改。
6. 查看右侧修改列表，点击“应用修改”，阅读影响并勾选确认后，程序才会备份并写入。

读取、获取图标、编辑和撤销都不会修改 iPhone。确认后的“原样写回校验”“应用修改”或“从备份恢复”会写入。导入备份文件只供预览，不能直接写到另一台手机；恢复必须先读取对应设备，再选该设备自己的完整备份；当前状态、目标备份和设备型号均须通过写入能力检查。

**应用和恢复都会替换整份主屏幕布局。** iOS 可能把仅留在 App 资源库的应用重新加入主屏幕；恢复旧备份也不能撤销这一系统行为。主屏幕备份不包含应用数据、照片、壁纸或整机系统状态。

如果手机上的布局在读取之后发生了变化，应用会停止写入，要求重新读取。无法理解的布局结构会被拒绝；未知内容必须保持原样。写入失败或读回结果不符时，不自动重试或自动恢复，先检查提示和备份。

## 本机数据

| 内容 | 位置 |
|---|---|
| 备份、日志和设置 | `~/Library/Application Support/HomeSpread/` |
| 离线草稿 | 资料目录中的 `drafts/` 或保存时选择的目录；扩展名 `.hsdraft` |
| 每台设备的备份 | `backups/<设备标识的 SHA-256>/` |
| 新建的本地设备配对凭据 | `~/Library/Application Support/HomeSpread/pairing/` |
| 可重新下载的图标 | `~/Library/Caches/HomeSpread/icons/` |
| 对应修改源码与依赖清单 | `.app/Contents/Resources/` 中的 `HomeSpread-source.zip` 与 `dependency-inventory.json` |

每份备份由 `.plist`、可读 `.json`、校验用 `.meta.json` 组成，移动或存档时保留三者和原设备目录。恢复时会检查设备归属与 SHA-256。旧版没有归属记录的备份可预览，不能用于恢复。

数据文件使用当前用户私有权限；它们没有单独加密。诊断报告含应用清单、文件夹名和设备信息，分享前应检查内容。应用不自动上传数据、不自动更新，也不会自动打开赞助链接。详见 [中文隐私说明](PRIVACY.zh-CN.md)。

## 从源码运行或重新构建

构建环境为 Apple Silicon Mac（macOS 14 或更新）和 Python 3.12。macOS 包为 arm64，不是 Intel 通用包；仅本机 macOS 27.3 已实际验证。

```sh
./install_macos.command
./run_macos.command
./run_probe_macos.command          # 只读诊断并备份，不写手机
./build_macos.command             # 生成 dist/HomeSpread.app
```

`install_macos.command` 安装 `requirements-macos.lock` 中锁定的 93 个运行时依赖；`requirements-build.txt` 是打包、测试和审计工具。首次创建虚拟环境时可用 `HOMESPREAD_PYTHON=/路径/python3.12` 指定解释器。安装脚本遇到任何失败会停止。

```sh
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
./run_macos.command --demo             # 虚构布局，无法写入手机
./run_macos.command --language zh_CN   # 也支持 en、ko
.venv/bin/python -m pip_audit --progress-spinner off
```

测试可用 `HOMESPREAD_DATA_DIR` 和 `HOMESPREAD_CACHE_DIR` 指定隔离目录。依赖升级须重新审计、运行测试，再运行 `scripts/lock_macos.py` 更新版本快照。构建过程不修改锁文件。锁文件固定版本，未固定下载文件哈希。

`.app` 使用本地临时签名（ad-hoc），未经过 Apple Developer ID 签名或公证。它用于这台电脑上的本地运行；向其他电脑分发前需另行处理签名、公证及适配验证。无需关闭 Gatekeeper 或 SIP。

## 验证边界

`mac.zh.3` 源码验证为 431 项测试、439 项子测试通过。离线草稿的保存、重放、撤销/重做、差异显示和设备隔离见 [离线草稿验收](_workspace/06_offline-draft-qa.md)。纯编辑规则从研究阶段提升到 `ipsm.draft_rules`，本机文件层为 `ipsm.drafts`；不包含协议发送或写入能力。


初版移植的 173 项测试记录见 [_workspace/04_macos-qa_final-report.md](_workspace/04_macos-qa_final-report.md)。这些测试遗漏了带空 `iconLists` 的真实小组件结构，不能作为小组件或 Duo 写回证据。此前小组件修复阶段的 264 项测试、383 项子测试通过，mac.zh.2 应用包的签名及离线启动核验通过。识别、跨格预览、离线模式及写入拒绝的验证见 [小组件与 Duo 验收](_workspace/05_widget-duo-qa.md)。

已在获授权的 iOS 27.3 设备上验证 USB 发现、连接、读取主屏幕、读取网格尺寸和创建校验备份。设备清单和原始布局保留在本地，不随源码公开。尚未执行真实 `setIconState`、原样写回或恢复；软件测试不能代替对应 iOS 版本的真实写入验证。

详细审计发现、修复与残余风险见 [安全审计报告](SECURITY_AUDIT.zh-CN.md)。上游文档中的 iPhone 14 / iOS 26.1 写入结果是上游历史记录，不能作为此 macOS 修改版的写入验收。
