# Microsoft Store 제출 준비 점검표

**작성:** 2026-08-20 · **대상:** HomeBoard v1.0
**표기:** `[확인됨]` 1차 출처로 확인 · `[추정]` 근거는 있으나 우리가 직접 확인하지 못함 ·
`[미확인]` 계정·기기가 있어야 알 수 있음

---

## 1. 먼저 답이 나온 것

| 물음 | 답 | 근거 |
|------|-----|------|
| GPL 프로그램을 스토어에 올려도 되는가 | **된다** | 개발자 계약은 개발자가 **자기 라이선스 약관을 대신 제출**하는 것을 허용하고, FOSS 가 요구하는 범위에서 표준 약관의 역공학·복제·재배포 금지 조항을 **넘어서도록 명시적으로 허락**한다. VLC 가 이 경로로 올라가 있다 `[확인됨(2차)]` |
| 후원 버튼을 PayPal 로 두어도 되는가 | **된다 — 아무것도 돌려주지 않는 한** | 정책 10.8.2: 자발적 후원은 Microsoft 결제 API 또는 **안전한 제3자 결제 API**로 받을 수 있다. 단 그 대가로 디지털 재화·기능·광고 제거를 주면 즉시 인앱 구매 API 로 넘어가야 한다 `[확인됨]` |
| 개인 계정으로 되는가, 회사 계정이 필요한가 | **개인 계정으로 된다** | 정책 10.8.3 의 회사 계정 요구는 **주 기능**이 금융 정보를 요구할 때다. 우리 주 기능은 홈화면 편집이고 후원은 곁가지다 `[확인됨]` |
| 개인정보 처리방침이 필요한가 | **반드시 필요하다** | 정책 10.5.1: Win32/데스크톱 브리지 제품은 **언제나** 개인정보 처리방침을 둔다 `[확인됨]` |
| MSIX 로 묶으면 `127.0.0.1:27015` 가 막히는가 | **막히지 않을 것이다 — 단 확인 전** | 막히는 쪽은 AppContainer 로 도는 앱이다. `Windows.FullTrustApplication` 으로 묶은 데스크톱 앱은 AppContainer 밖에서 돌아 일반 데스크톱 앱과 같은 권한을 갖는다 `[추정]` → **실제 패키지로 시험해야 한다** `[미검증]` |

## 2. 포장 방식 — 두 갈래

> 2026-08-21: 어느 쪽으로 가든 필요한 **폴더 배포(onedir)로 이미 전환했다** —
> `dist\HomeBoard\`. MSIX 는 exe 하나를 감싸는 그릇이 아니라 파일 목록을 담는
> 그릇이라 이 모양이 전제다. 덤으로 시작 시간이 21초 → 2.3초가 됐다.

| | MSIX 로 묶어 올리기 | 직접 내려받기 링크 (정책 10.2.9) |
|---|---|---|
| 사용자 경험 | 스토어에서 설치·갱신이 자동 | 스토어가 우리 서버의 설치 파일로 보낸다 |
| 서명 | 스토어가 맡는다 | **우리가 코드 서명 인증서를 사야 한다** |
| 조건 | 게임 아님 · 표준 심사 | HTTPS 직접 링크 · 서명된 .msi/.exe · 조용한 설치 지원 |
| 위험 | 루프백 `[미검증]` · 파일 쓰기 경로 가상화 | 갱신·호스팅을 우리가 떠맡는다 |

**권하는 순서:** MSIX 로 먼저 시험한다. 루프백과 `backups/` 쓰기가 통하면 그대로 간다.
막히면 10.2.9 로 물러선다. 이 결정은 **실제로 묶어 보기 전에는 내리지 않는다.**

> 자료 폴더 주의: MSIX 는 exe 옆에 쓰는 것을 가상화한다. 지금 `paths.data_root()` 는
> exe 옆을 쓴다. MSIX 로 간다면 `LocalAppData` 로 옮겨야 할 수 있다 `[미검증]`.
> 백업이 사용자가 찾을 수 없는 곳에 숨는 것이 가장 나쁜 결말이다.

## 3. Partner Center 에 채워 넣을 것

- [ ] **앱 이름** — `HomeBoard`. 이름 칸에 Apple 상표를 넣지 않는다. 부제
      `Mobile layout manager for iOS` 는 이름 아래 자리에만 쓴다
- [ ] **이름 선점 가능 여부** `[미확인]` — Partner Center 에서 예약해 봐야 안다
- [ ] **상표 검색** `[미확인]` — 'HomeBoard' 를 쓰는 다른 등록 상표가 있는지
- [ ] **개인정보 처리방침 URL** — 저장소의 `PRIVACY.md` 를 가리킨다. 저장소가 공개되어야 생긴다
- [ ] **제3자 결제 API 사용 선언** (10.8.2) — PayPal 후원을 쓴다는 사실을 신고한다
- [ ] **자기 라이선스 약관 제출** — 표준 약관 대신 GPL-3.0-or-later 를 올린다
- [ ] **연령 등급(IARC 설문)** — 수집·공유가 없으므로 대부분 '아니오'
- [ ] **지원 연락처** — `forad@ujak.net`
- [ ] **스크린샷** — 최소 1366x768. 여러 페이지가 한 화면에 펼쳐진 장면이 핵심이다
- [ ] **스토어 로고** 300x300 이상
- [ ] **설명문** (한국어·영어) — "Apple Devices 가 필요하다"를 **첫 문단에** 적는다.
      준비물을 모르고 받은 사람이 첫 화면에서 막히면 그대로 별 하나가 된다
- [ ] **적용 시 부작용 고지** — 앱 라이브러리에만 있던 앱이 마지막 페이지 끝에 붙는다.
      프로그램도 미리 알리지만 설명문에도 적는다

## 4. 올리기 전에 반드시 끝내야 하는 것

1. **`product.SOURCE_URL` 채우기** — 공개 저장소 주소. GPL 은 실행 파일을 받은 사람에게
   소스에 닿을 길을 주기를 요구한다. 지금은 비어 있고, 비어 있으면 정보 창이 "배포한
   사람에게 요청하라"고만 말한다. 스토어 배포는 그 상태로 하면 안 된다
2. **MSIX 실제 패키지로 루프백·백업 쓰기 시험**
3. **다른 기기·iOS 판에서 한 번 더 왕복** — 지금 확인된 것은 iPhone 14 / iOS 26.1 하나뿐이다
