## 重点检查

| 边界 | 验证 |
|---|---|
| 格式 3 不是完整布局 | 按整份观察测试压缩投影；False 的解释仅在完整匹配时输出，几何验证始终为假 |
| 类型与未知内容 | `False`/`0`、`True`/`1`、日期精度、字节、额外字段、页与顺序变化均不能被相等判断掩盖 |
| 普通 App 分类 | 未知 iconType、网页快捷方式和其它不支持项目不计为普通 App |
| 数量口径 | 区分顶层 App、文件夹内出现位置、安装条目；组件扩展不当作 App |
| 标签和卸载占位 | 缺失、显式空标签、hidden 分别统计；非布尔占位标记被拒绝；空查询不证明覆盖完整 |
| 标识匹配 | 多个已知别名和 User/System 重叠会使覆盖检查失败，不生成可发送排除清单 |
| 组件标识 | 独立组件源字段缺失、目标字段无效和冲突分别报告，堆叠不套用独立组件规则；不修改输入 |
| 离线与隐私 | 纯分析在文件、网络和设备导入陷阱下运行；输出不含测试中的私人名称、ID、UUID、字节或原始字典 |
| 文件与停止 | 不覆盖输入/已有报告；私有文件权限与读回；读取失败不进入保存，保存失败只尝试一次且不输出异常中的私人内容 |
| 收据边界 | CLI 拒绝导入备份、未完成采集及前后布局/身份不一致的记录，不自动补采或刷新时间 |

## 独立审查发现

初版分类函数在参考格式中把未知 `iconType` 及部分网页快捷方式标记误计为普通 App。五个独立反例失败后，已按现有草稿模型的允许类型和全部网页快捷方式标记修复，复验通过。该问题影响报告数量，不会放行写入；没有发生真实设备操作。

## 保留的限制

投影匹配只说明保存数据之间的关系，不能推广为所有系统版本的格式 3 规范，不能证明真实屏幕坐标。安装查询未包含所有可见性条件，未匹配项不等于资源库 App 或完整 `ignored`。组件标识存在也不能证明内部配置保持。

工具没有实际发送接口，不生成候选请求；真实几何、隐藏页面、组件配置、排除语义及写入行为仍需独立证据。后续步骤和停止条件见[离线证据分析说明](../research/DUO_EVIDENCE_ANALYSIS.zh-CN.md)。
