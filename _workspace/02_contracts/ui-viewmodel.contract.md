# 계약: ui-viewmodel

**소유자:** ui-engineer
**구현:** `src/ipsm/ui/` (`worker.py`, `tiles.py`, `canvas.py`, `main_window.py`), `src/ipsm/app.py`
**상태:** 실기기에서 편집→적용까지 확인됨 (2026-08-20, 2회 적용 · 손실 0)

화면과 그 아래층 사이의 경계.

## 경계 규칙

| 규칙 | 이유 |
|------|------|
| **Qt 는 `src/ipsm/ui/` 아래에서만 안다** | `layout.py` · `iconstate.py` · `device.py` · `backup.py` · `icons.py` 는 Qt 없이 시험할 수 있어야 한다 |
| 화면은 판정하지 않는다 — 전부 `LayoutDocument` 에 묻는다 | 판단이 두 곳에 있으면 갈린다 |
| 기기 작업은 워커 스레드에서만 | 쓰기 도중 창이 얼면 사용자가 케이블을 뽑는다 |
| 결과는 시그널로만 건넌다 | 기기 객체를 두 스레드에서 만지면 언젠가 깨진다 |

ADR-001 이 PySide6 를 고른 결정적 이유도 이 경계다. UI 와 기기 층이 **같은 파이썬 객체**를
쓰므로, 우리가 해석하지 못한 필드가 직렬화 경계에서 조용히 떨어져 나갈 자리가 없다.

## DeviceWorker (QThread)

```python
# 성공
loaded(state, metrics, DeviceInfo)
installedListed(dict)          # 번들 ID → 이름
iconsUpdated(fetched, requested)
applied(dict)                  # backup, comparison, state
restoredFrom(dict)
backupsListed(list)
# 상태
progressed(message, done, total)
busyChanged(bool)
failed(what_went_wrong, what_to_do)
```

- 작업은 **한 번에 하나.** 큐를 두지 않는다 — 큐에 쌓인 작업은 사용자가 잊은 뒤에
  실행되고, 이 앱에서 '잊은 뒤에 실행되는 것' 중 하나는 홈화면 덮어쓰기다.
- `failed` 는 항상 **두 문장**이다: 무엇이 잘못됐는가 + 무엇을 하면 되는가.
- `load()` 는 홈화면을 먼저 띄우고 **그다음에** 설치 목록을 받는다. 부가 정보 때문에
  화면이 늦게 뜨면 순서가 거꾸로다.
- `shutdown()` 은 두 번 불려도 안전해야 한다 (창 닫기 + 앱 정리가 모두 부른다).

## 화면 규약

| 규약 | 이유 |
|------|------|
| 한 페이지 = 위젯 하나가 모든 칸을 그린다 | 300개가 넘는 아이콘. 칸마다 위젯을 두면 창이 느려진다 (REQ-012) |
| 다시 그리기는 항상 `QTimer.singleShot(0, …)` 로 미룬다 | 드롭 처리 도중 그 드롭을 받은 위젯을 지우면 앱이 죽는다 |
| 아이콘 한가운데(62%) 안 = 폴더 안, 밖 = 폴더 옆 | 두 뜻을 한 동작에 담되, 경계를 눈에 보이게 그린다 |
| 폴더는 새 창이 아니라 같은 창 **아래쪽**에 편다 | 폴더 안팎으로 끌려면 두 자리가 동시에 보여야 한다 |
| 거절할 드롭은 `dragMoveEvent` 에서 `ignore()` | 손을 놓기 **전에** 커서가 '금지'로 바뀌어야 한다 |
| 페이지 순서 바꾸기는 버튼(◀ ▶)으로 | 드래그 체계를 둘로 만들면 어느 쪽이 잡혔는지 모르게 된다 |
| 앱 위 62% 안 = 새 묶음 (대상이 폴더면 폴더 안) | 사용자는 이 둘을 다른 손짓으로 여기지 않는다 |
| 판은 묶지 않는다 — `grouped(끌어온 uid, 놓인 uid)` 만 알린다 | 이름을 묻기 전에 묶여 버리면 취소해도 늦다 |
| 선택 집합은 `MainWindow.selection` 하나뿐 | 판마다 들고 있으면 페이지를 건너 여럿을 고를 수 없다 |
| 다시 그릴 때 사라진 uid 는 선택에서 뺀다 | 없는 것을 고른 채로 두면 '묶기'가 켜져 있는데 눌러도 아무 일이 없다 |
| 스타일시트에서 `color` 를 정하면 `background` 도 같이 정한다 | 한쪽만 정하면 나머지는 Windows 기본값이라, 어두운 바탕의 검은 글씨나 흰 바탕의 흰 글씨가 된다 |

## 적용 화면 (ApplyDialog)

적용은 **읽기 → 펼치기 → 편집 → 변경 목록 확인 → 백업 → 쓰기 → 결과 대조** 순서를 따른다.

대화상자가 반드시 말하는 것:

1. 적용 전에 자동 백업하며, 백업이 실패하면 쓰지 않는다
2. 홈화면은 부분 수정이 아니라 **전체가 한 번에 덮어써진다**
3. **지금 홈화면에 없는 앱이 마지막 페이지 끝에 붙는다** — 몇 개인지, 어떤 앱인지
   이름까지. iOS 동작이라 **백업 복원으로도 되돌아가지 않는다**
4. 적용 중에 케이블을 뽑지 말 것

"위 내용을 확인했습니다"를 체크하기 전에는 적용 버튼이 꺼져 있다.

미배치 앱은 대화상자에서 처음 보여서는 안 되므로, 편집하는 동안 **곁판에 늘 보이는
자리**를 따로 둔다.

- 변경이 없다 → 끈다

## 말 (i18n)

한 곳(`ipsm.i18n`)에서 고른다. **원문이 곧 열쇠**다 — `tr("취소")` 처럼 한국어를
그대로 적고, 사전(`translations_en.TRANSLATIONS`)에 없으면 원문을 돌려준다. 번역이
빠져도 앱이 말을 잃지 않는다. 빈칸보다 한국어가 낫다.

| 규약 | 이유 |
|------|------|
| **로그는 번역하지 않는다** | 로그는 우리가 읽는 것이고, 언어가 섞이면 같은 사건을 검색으로 모을 수 없다 |
| 값은 `tr("...{n}개").format(n=…)` 으로 넣는다 | 완성된 문장을 열쇠로 삼으면 숫자마다 열쇠가 생겨 사전이 끝없이 늘어난다 |
| 문장은 조각내지 않는다 | 조사가 붙은 조각("독이")은 다른 말로 옮길 수 없다 |
| 언어 목록(`LANGUAGES`)의 이름만은 `tr()` 을 거치지 않는다 | 읽지 못하는 말로 켜진 사람이 목록에서 자기 말을 찾을 수 있어야 한다 |
| 문구를 넣은 자리마다 `MainWindow.retranslate()` 에 짝이 있다 | Qt 는 한 번 넣은 글자를 스스로 바꾸지 않는다. 짝이 없으면 그 위젯만 옛 말로 남는다 |
| 창 제목의 기기 이름은 완성된 문장이 아니라 `(무엇인지, 값)` 으로 들고 있는다 | 지어 둔 문장은 언어가 바뀌어도 그대로다 |
| 캔버스는 짝을 적지 않고 통째로 다시 짓는다 (열어 둔 묶음은 되살린다) | 판·타일의 문구를 일일이 따라다니면 빠뜨린다 |
| 창을 닫을 때 `off_language_changed` 로 명단에서 뺀다 | 지워진 창을 다시 그리려다 터진다 |

고른 언어는 `settings.json` (자료 폴더 안)에 남는다. `app.py` 는 `i18n.start()` 를
**`ensure_ready()` 보다 먼저** 부른다 — 시작하다 실패했을 때 뜨는 말도 사용자의 말이어야
한다. 저장된 값이 없으면 PC 언어를 따르고, 한국어 PC 가 아니면 영어로 연다.

빠뜨린 번역은 사람 눈이 아니라 시험이 잡는다 (`test_every_translatable_string_has_an_english_entry`,
`test_translations_keep_the_same_placeholders`, `test_the_window_changes_its_words_when_the_language_changes`).

## 시작 안내판 (GuideBoard)

읽기 전에는 캔버스 자리를 **안내판이 대신 채운다**. 빈 화면으로 맞이하면 무엇이 없어서
안 되는지가 "기기에서 읽기"를 누른 뒤의 오류 상자에서야 드러난다.

| 규약 | 이유 |
|------|------|
| 준비됐는지는 **`127.0.0.1:27015` 가 열려 있는가** 하나로 판단한다 | Apple 쪽 구성요소가 USB 를 맡으면서 여는 자리다. 무엇이 열었든 상관없다 |
| 설치 폴더는 **할 말을 고르는 데만** 쓰고 길을 막는 데 쓰지 않는다 | 이름으로 찾는 짐작은 Apple 이 폴더를 바꾸면 틀린다. 틀렸을 때 손해가 작은 쪽으로 쓴다 |
| 27015 가 열려 있으면 설치 여부는 **묻지도 않는다** | 말이 통하는 것이 확인됐는데 그 위에 짐작을 얹을 이유가 없다 |
| 세 갈래로만 말한다 (준비됨 · 안 떴음 · 없음) | 갈래마다 사용자가 다음에 할 일이 다르다. 없는 사람에게 "실행하세요"라고 하면 안 된다 |
| 3초마다 스스로 다시 본다 | 옆에서 설치를 끝냈는데 화면이 그대로면, 다 해 놓고도 안 된다고 여기게 된다 |
| 안내판과 캔버스는 같은 자리를 나눠 쓴다 (`_show_guide`) | 둘 다 보이면 어느 쪽도 넓지 않다. 문서가 오는 순간 자리를 넘긴다 |
| 확인은 화면 실타래에서 하되 **시간 제한(0.4초)** 을 둔다 | 같은 PC 안이라 곧바로 끝나지만, 방화벽이 응답을 삼키면 화면이 멎는다 |

Store 로는 딥링크(`ms-windows-store://pdp/?PFN=…`)로 데려가고, 듣지 않으면 검색으로
되돌아간다 — 지역·버전에 따라 딥링크가 열리지 않는다.

시험: `test_the_open_port_decides_readiness_not_the_folder`,
`test_the_guide_tells_the_user_what_to_do_next`,
`test_the_guide_hands_its_place_to_the_canvas`.

## 색 (글씨가 바탕에 묻히지 않기)

**글자색을 정하는 자리에서는 바탕색도 같이 정한다.** 맨 위의 `QWidget { color: … }` 이
모든 위젯의 글자를 밝게 칠하므로, 바탕을 두지 않은 위젯은 Windows 기본 흰 바탕에 흰
글씨가 된다. 같은 실수가 세 번 났다 — 도구모음(반대 방향), 이름 바꾸기 입력칸,
언어 목록.

세 번째는 위젯을 하나 더 알아야 잡힌다: **`QComboBox` 를 칠해도 펼쳐지는 목록은
칠해지지 않는다.** 목록은 그 안의 `QAbstractItemView` 라서 `QComboBox QAbstractItemView`
로 따로 칠해야 한다. 접힌 칸만 보고는 알 수 없다.

그래서 눈으로 훑지 않고 **실제로 그려서 밝기 차를 잰다** —
`test_dialog_text_is_readable_on_its_own_background`,
`test_the_dropdown_list_is_readable_too` (펼친 뒤에 잰다).

## 이름과 후원 (설정 창)

| 규칙 | 이유 |
|------|------|
| 화면에 나가는 문자열에 제품 이름을 직접 적지 않는다 — `product.NAME` 을 읽는다 | 이름을 바꿀 때 고칠 자리가 하나여야 한다. `test_the_name_is_declared_once` 가 설명글을 뺀 모든 문자열을 훑어 막는다 |
| 이름에 `iOS`·`iPhone` 을 넣지 않는다. 호환성 표기는 `TAGLINE` 으로 | Apple 상표 지침이 이름 칸을 금지하고 부제만 허용한다. `test_the_store_name_carries_no_apple_trademark` |
| 후원 주소는 `product.donate_url()` 이 짓는다 — 창이 잇지 않는다 | 계정이 바뀔 때 고칠 자리 하나. 창을 띄우지 않고도 주소를 시험할 수 있다 |
| 설정 창을 여는 것만으로는 아무 데도 연결하지 않는다. **누를 때만** 브라우저가 열린다 | 창이 뜨자마자 밖으로 나가면 사용자가 모르는 사이에 흔적이 남는다. `test_the_settings_offers_support_without_going_anywhere_by_itself` 가 `QDesktopServices` 를 가짜로 바꿔 확인한다 |
| 후원의 대가로 아무것도 주지 않는다 | Store 정책 10.8.2 — 대가가 붙는 순간 외부 결제가 아니라 Microsoft 인앱 결제를 써야 한다 |
| 주소에 `no_recurring=1` | 한 번 응원하려던 사람이 정기 결제에 들어가는 일이 없어야 한다. `test_the_donate_link_reaches_the_right_account` 가 계정·통화와 함께 확인한다 |

## 진단

실기기 세션의 진단은 전부 `logs/` 로 간다. 사용자는 "안 떠요"라고만 말할 수 있고,
그때 우리가 볼 수 있는 것은 로그뿐이다. 그래서 `app.py` 는 **Qt 를 import 하기 전에**
로그 세션을 연다.
