# 布局读取与提取流水线

把设备上的实际主屏幕转换为 `observed` 布局。

当前实现直接读取原始 iconState，再解析为视图；本文也保留历史截图、无障碍树提取方案。后者没有接入当前产品，涉及翻页或打开文件夹的步骤不是当前读取的必要条件。

## 1. 流水线阶段

### 当前路径

```text
USB 连接与信任
  ↓
读取原始 iconState，保留未知字段
  ↓
读取网格信息，解析页面、程序坞、文件夹及项目
  ↓
检查可否原样表示，建立 observed 与编辑基线
  ↓
显示布局；再获取安装列表及所需图标作为补充
```

安装列表失败不等于布局读取失败，但界面不能据此承诺“没有 App 资源库应用会重新出现”。缺少网格信息时，明确采用何种默认值及未验证限制。

### 历史识别流水线

```text
[1] 确定设备配置
 ↓
[2] 查询已安装应用 → {bundle ID → 名称、图标}
 ↓
[3] 遍历页面
 ├─ 无障碍结构转储
 └─ 截图
 ↓
[4] 坐标映射为网格位置
 ↓
[5] 对照目录及图标识别应用
 ↓
[6] 交叉验证与置信度计算
 ↓
[7] observed 布局
```

### 各阶段原则

**[1] 先确定配置。** 坐标映射依赖网格。未知设备可进入测量研究，但推断配置不能直接授权自动修改。

**[2] 先准备识别目录。** 该顺序只适用于历史图像识别路径，避免识别每个图标时反复访问设备；当前 plist 路径先显示布局，再获取补充安装信息。

**[3] 遍历会改变界面状态。** 参见 `../../ios-device-protocol/references/capture-and-structure.md`。保留各页原始数据，解析失败时仍可离线复查。

**[4] 用图标图像区域映射位置。** 若把标签文本算入中心点，行判断可能向下偏移。

**[5] 识别失败是正常结果。** 系统项目、小组件和主题图标可能无法识别，应保留为 `Unknown`，不能丢弃或当作空位。

**[6] 验证后才能输出可用状态。** 展示不完整结果与允许对设备写入是不同的权限。

## 2. 部分失败处理

历史逐页提取中，读完前三页后在第四页失败，前三页仍有诊断价值，可返回：

```text
ExtractionResult
  layout         ：已读到的局部布局
  completeness   ："complete" | "partial"
  failedAt       ：页码与阶段
  failureReason  ：原因
  rawArtifacts   ：原始转储与截图路径
```

`partial` 不能用于建立自动修改计划，更不能作为整份布局写回。缺失区域中可能存在任何项目。应由明确结果类型和写入边界阻止，而非只依靠界面提示。

当前直接读取路径也必须拒绝不支持或不完整的顶层结构；解析器能展示部分内容，不表示它能安全重建整份数据。

## 3. 交叉验证

下表适用于历史识别路径；当前路径应采用原始结构、身份保留和往返检查。

| 检查 | 可能含义 | 处理 |
|------|----------|------|
| 两项目映射到同一位置 | 配置或检测错误 | 判定失败，重新测量 |
| 位置超出网格 | 原点或尺寸错误 | 判定失败 |
| 无障碍图标数与图像识别数不同 | 漏检或重复检测 | 降低置信度并诊断，禁止把缺失当空位 |
| 标识匹配率过低 | 目录或识别不完整 | 受控重查，不无限重试 |
| 页数与指示器不同 | 遍历漏页或重复 | 标记 `partial` |
| 同一标识位于多个位置 | 真实重复或误识别 | 按模型的重复出现规则区分，不能直接去重 |

位置冲突是失败条件，不是可以忽略的警告。错误坐标一旦用于触控，可能改变错误内容。

## 4. 确定性与稳定等待

读取会用于首次加载、写后校验；历史手势方案还用于每一步验证。

- 同一稳定状态应产生相同结果，否则比较会产生误报。
- 等待动画结束，或在适当场景比较连续读取；不要把固定等待时间当作设备一定完成的证明。
- 若采用置信度，计算必须可复现，避免同一输入导致界面标记闪烁。
- 当前比较仅排除已确认的易变时间字段，不能一概忽略未知字段。

### 历史手势方案的轻量提取

逐步全量提取成本较高，因此研究方案提出只重读受影响页面。范围必须包含顺延可能传播到的全部页面，不能假设一次移动只影响一两页；根据已验证规则和 `allowsGaps` 等配置确定。

当前整体 plist 写入使用完整重读比较，不能为追求速度而用未经验证的局部截图代替。

## 5. 历史提取结果格式

下面是候选接口，不是当前代码已经实现的数据类：

```text
ObservedLayout
  schemaVersion   ：模式版本
  extractedAt     ：提取时刻
  deviceProfile   ：配置，包括 source 与 verification
  completeness    ："complete" | "partial"
  pages[]         ：各页位置布局
  dock            ：程序坞
  unplaced[]      ：不在主屏幕上的已安装应用
  diagnostics
    slotConflicts ：位置冲突列表
    unresolvedCount：Unknown 数量
    matchRate     ：可靠标识匹配率
    warnings[]    ：交叉验证警告
```

若实施此接口，`diagnostics` 必须提供：界面需要说明无法识别的项目数，QA 需要追踪质量。当前产品相关事实以现有契约和实际类型为准。
