## 1. 设备安全

### 当前整体写入

- [ ] 所有实际写入均经过受保护路径，GUI、原样校验、恢复与 CLI 没有旁路。
- [ ] 写入前备份唯一、可读、与原始数据一致；失败时设备写入次数为零。
- [ ] 备份完整性和设备归属得到校验，不能跨设备恢复。
- [ ] 当前编辑基线过期时拒绝写入，并说明重新读取的下一步。
- [ ] 会话未验证时不能应用编辑；普通路径需要明确确认的原样写回校验。
- [ ] 明确确认的恢复仍可在未验证或校验失败后执行；成功恢复且读回比较通过也可建立当前会话的编辑权限。
- [ ] 新读取或操作失败会清除会话校验状态。
- [ ] 未知原始字段和位置保持不变，不能把缺失内容当空位。
- [ ] 写后比较丢失、移动、内容变化及新增项目。
- [ ] USB 断开或写入异常时保留备份与诊断，不自动重试或声称回滚成功。
- [ ] 正在进行设备操作时阻止关闭，避免强行结束线程。
- [ ] 说明 App 资源库应用回填，以及备份不能自动撤销该行为。

### 历史手势研究

- [ ] 断开时保留检查点，恢复前比较 `lastVerified` 与实际状态。
- [ ] 应用意外打开时，停止并回到正确界面后重新读取和规划。
- [ ] 确认进入编辑模式后才发拖动。
- [ ] 成功、失败和取消均处理退出编辑模式，并验证结果。
- [ ] 锁定、来电等干扰使执行暂停或停止。
- [ ] 推断配置明确标记，不能直接当成已验证前提。
- [ ] 位置冲突使提取失败，不能仅警告后继续。
- [ ] 低置信度小组件与未知项目排除自动移动。
- [ ] 重试前读取当前状态，避免重复部分成功的手势。

## 2. 各模块边界

### 读取或提取层 ↔ 布局模型

- [ ] 当前原始 plist 的顶层、程序坞、页面和文件夹格式一致。
- [ ] 不支持的结构保留并阻止不安全写入。
- [ ] 如启用历史 `ExtractionResult`，字段、`completeness`、`diagnostics` 和置信度含义在两端一致。
- [ ] 诊断信息实际填充并被消费，而非只有类型定义。

### 布局模型 ↔ 界面

- [ ] Unknown 到达界面且不可移动。
- [ ] 未放置应用提示正确使用安装列表，并承认信息可能不完整。
- [ ] 界面调用模型约束，不自行复制规则。
- [ ] 原始状态与编辑目标分开管理。
- [ ] 修改列表、撤销和重新读取对编辑状态的影响一致。

### 布局模型 ↔ 同步层

- [ ] 页面、程序坞和文件夹容量均有检查。
- [ ] 写出数据从原始结构派生，未识别内容没有消失。
- [ ] 当前安全校验在实际写入边界执行，不只依赖界面。
- [ ] 如实施历史模拟器，其 `allowsGaps`、置信度门槛与配置来源符合契约。

### 同步层 ↔ 设备桥接

- [ ] 仅选择明确的 USB 设备，多个设备时不默选。
- [ ] 原始状态传递和备份顺序一致。
- [ ] 超时单位、失败表达一致。
- [ ] 当前路径没有未经授权的重试或无线回退。
- [ ] 历史手势路径另行核对坐标单位、失败与取消信号，不能套用到当前整体写入。

### 同步层 ↔ 界面

- [ ] 发出的事件与订阅事件匹配。
- [ ] 校验失败、写入异常和需要人工检查的结果不显示成成功。
- [ ] 恢复入口及会话标记更新与后台一致。
- [ ] 历史预演和部分完成结果若被实现，包含界面所需全部信息，且不把部分完成简单标成全部失败。

## 3. 坐标审查

用 `rg` 搜索全部坐标相关标识符并逐处核对：

- [ ] 名称或类型体现坐标系。
- [ ] 转换集中在约定位置。
- [ ] 原点与方向符合契约。
- [ ] 明确是否应用 DPI 或 Retina 缩放。
- [ ] 如处理截图，中心按图标图像区域计算，不把标签纳入。

当前检查画布和网格坐标；设备物理坐标只属于历史手势方案。

## 4. 错误处理路径

从错误源追踪到用户可见提示，确保有下一步。

| 情况 | 是否有提示 | 是否说明下一步 |
|------|------------|----------------|
| 未连接设备 | | |
| 未建立信任或设备锁定 | | |
| 多台 USB 设备 | | |
| 依赖缺失或版本不兼容 | | |
| 读取不完整或结构不支持 | | |
| 备份失败或完整性失败 | | |
| 备份不属于当前设备 | | |
| 编辑基线过期 | | |
| 写入或校验时断线 | | |
| 历史路径：开发者模式关闭 | | |
| 历史路径：签名失效 | | |
| 历史路径：推断配置或连续失败 | | |

- [ ] 用户能理解提示，而非只收到原始异常。
- [ ] WDA、usbmuxd、lockdownd 等内部术语不无故进入操作流程。
- [ ] 诊断保留足够技术信息，但按隐私规则脱敏，不泄漏配对材料。

## 5. 用户体验

- [ ] 未连接时显示有效指南，读取成功后切换到画布；不能要求空白画布取代首次连接说明。
- [ ] 未应用修改数持续可见。
- [ ] 关闭未应用编辑前提示。
- [ ] 拖动期间展示可用目标。
- [ ] 顺延行为可理解；未实现的完整预览应记录为限制，而非宣称已完成。
- [ ] 一次拖放及其连带变化可用一次撤销恢复。
- [ ] 设备操作期间有进度，界面保持响应并阻止危险关闭。
- [ ] 整体写入不显示虚假的“随时立即取消”；历史手势方案若启用，才检查安全点取消。
- [ ] 校验结果明确列出异常与 iOS 新增项目。
- [ ] 历史部分执行方案若启用，分别列出完成与剩余事项。

## 6. 桌面平台

### macOS

- [ ] Apple Silicon 构建和 `.app` 启动可用，依赖无需用户手工安装。
- [ ] 通过系统 USB 服务检测就绪，不显示 Microsoft Store 安装指引。
- [ ] 中文、⌘ 快捷键、Retina 显示与窗口缩放可读可用。
- [ ] 数据、日志、备份和配对材料位于正确的私有数据目录，图标缓存与其区分。
- [ ] 应用包移动后，资源和随附源码仍可定位。
- [ ] 不要求关闭系统安全功能来启动普通本地构建。

### Windows 与共同检查

- [ ] Windows 125%、150%、175% 缩放下坐标正确。
- [ ] 跨显示器移动时处理缩放变化。
- [ ] 画布随窗口大小调整。
- [ ] 连接、图标获取、备份和写后比较期间仍能响应；历史手势循环另测长时间运行。
- [ ] 若具体操作需要额外权限，提前解释实际原因。
- [ ] 资源或必要外部程序的定位不依赖固定安装路径。
- [ ] 含空格、中文和其他 Unicode 字符的路径可用。

## 7. 验收追踪

逐项对照 `_workspace/01_product-strategist_requirements.md` 中相关 `REQ-###`，区分当前范围和历史研究需求。

| 状态 | 含义 |
|------|------|
| 满足 | 有执行或明确代码审查证据，并注明证据类别 |
| 不满足 | 已检查且条件未成立 |
| 部分满足 | 仅满足部分条件 |
| 未验证 | 没有条件或授权验证，必须写原因 |

- [ ] 当前范围的全部要求均有记录，遗漏优先补齐。
- [ ] 不满足和未验证分开。
- [ ] 每个未验证项都有原因。
- [ ] 历史真实设备结果不冒充本次设备或构建的验证。
