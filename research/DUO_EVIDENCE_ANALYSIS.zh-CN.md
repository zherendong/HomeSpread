# Duo 已保存证据的离线分析

`research/duo_evidence_analysis.py` 对已导出的数据做结构、字段关系和数量核对；`scripts/analyze_duo_evidence.py` 加载已保存的 `.hsevidence`，生成本地 JSON 或中文文本报告。工具不连接手机、不构造写入载荷、不生成 `ignored` 清单，也不授予写入能力。已安装应用仍为 `mac.zh.4`，此研究工具从源码运行。

## 运行与文件边界

在仓库根目录运行，输入和输出都使用本机文件路径：

```sh
PYTHONPATH=src:. .venv/bin/python scripts/analyze_duo_evidence.py \
  --evidence '/path/to/evidence/device-readonly.hsevidence' \
  --output '/path/to/evidence/offline-analysis.txt'
```

输出父目录必须存在；只接受新的 `.json` 或 `.txt` 文件，不覆盖已有文件。保存采用私有权限、原子发布和读回核对。输入文件不会被修改。建议把输出放在证据包所在的 `evidence/` 目录；该目录已从 Git 和分发源码归档排除。

CLI 要求完整的 USB 只读收据，且前后布局、设备身份按二进制类型敏感比较一致。导入备份、模拟来源、未完成采集或不一致快照不能冒充完整观测。工具不会补采、重试或刷新原观测时间，也不会把过去的证据说成手机当前状态。

报告不输出 App 名称、包标识符、组件 UUID、设备指纹或原始字典。数量、组件位置及观测时间仍属于本地使用信息，不能因此把报告称为匿名或自动公开。真实结果保留在私有证据目录；仓库测试仅使用虚构数据。

## 格式 2 与格式 3

格式 2 是 Dock 加逻辑页面的原始列表。本分析器沿用受限草稿模型校验它，不把不支持的布局强制转换成已知类型。

对于格式 3，分别统计行、普通 App 字典、文件夹、小组件、`False` 和其它单元。逐页比较顶层普通 App 的顺序及完整值，包括未知字段、日期和布尔类型。不能只按名称或忽略字段后宣布相同。

工具检验一个明确的**候选投影**：

1. 按格式 2 的顶层顺序，每个项目取一格。
2. 普通 App 的完整字典保持原样，非 App 项目替为 `False`。
3. 每个容器尾部补 `False` 到四格倍数，再每四格分行。

只有整个结果与实际格式 3 精确一致，才报告非 App 替代格和尾部填充数。任意类型、字段、顺序、页数、行或补位差异都会使该解释不成立。`False` 与整数 `0` 不相等。

即使投影匹配，也只能说明两个导出的关系：组件在这个候选投影中占一格，不代表它在屏幕上只占一格；非 App 项目没有出现在格式 3，也不代表它从手机上被删除。不能用格式 3 重建文件夹内容、组件或真实空隙。`geometry_verified` 与 `false_means_empty` 恒为 `False`。

## 安装清单与排除语义

分别统计 User/System 的条目数、桌面标识匹配数、未匹配数、卸载占位数和标签字段覆盖。桌面普通 App 包括 Dock 与文件夹内容，组件扩展标识不算桌面 App。一个 App 多次出现是多个布局位置，不必等于多个安装条目。

未匹配项进一步分为：带 `hidden` 标签、没有返回标签字段、明确返回标签但不含 `hidden`。**字段缺失不能当作非隐藏，成功空清单不能当作完整清单。** 清单交集、一个桌面项目同时匹配多个安装标识及未覆盖的桌面项目均明确报告。

这些统计不裁决隐藏系统服务、条件性图标或隐藏网页快捷方式应怎样进入写入协议。工具只输出数量，不输出可执行排除清单；`exclusion_list_complete` 恒为 `False`。

## 小组件标识字段

报告区分堆叠与独立组件，记录成员数、`userSelectedElementIdentifier` 和 `uniqueIdentifier` 是否存在，以及堆叠选中标识匹配成员的数量。

独立组件的别名检查仅回答字段条件：源字段缺失、字段可用但未验证、已有值相同、已有值冲突或目标字段无效。堆叠不套用独立组件规则。工具不会复制、生成或猜测标识，字段存在也不证明城市、账户、组件内部参数等配置能在写回后保留。

## 后续证据与停止条件

离线分析可缩小协议假设，不能替代下面的独立证据：

| 待解决问题 | 具体核对 | 停止条件 |
|---|---|---|
| 实际位置与空隙 | 对照同一基线下每页、Dock 及折叠姿态的画面；明确哪些页未覆盖 | 无法对应的坐标或未记录页面不能当作已验证 |
| 隐藏页与专注模式 | 独立记录页面可见性，不从 USB 页面数组猜测 | 未知状态继续阻止完整保持声明 |
| 组件设置与身份 | 按组件分别记录顶部成员、自动轮换/建议及内部配置；区分缺字段和冲突 | 缺失标识不得生成随机 ID 或使用通配比较 |
| 排除清单语义 | 明确系统条目、卸载占位和隐藏网页快捷方式的来源与分类依据 | 不把安装集合减桌面集合直接宣布为完整清单 |
| 实际写入与失败行为 | 在上述证据和单次实验方案可审阅后，另行获得针对操作及副作用的授权 | 没有授权不发送；发送后不确定时不自动重发或恢复 |

这些核对不要求现在连接手机。读取现有截图可以做部分画面对照；缺少的画面或设置必须明确列出，不能扩大到未获授权的截图服务、其它个人资料或写入操作。
